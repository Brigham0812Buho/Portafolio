# Portafolio personal - Gary Chunga

Portfolio profesional desarrollado con Next.js, TypeScript y Tailwind CSS para presentar experiencia, proyectos y servicios con un estilo moderno y premium.

## Tecnologías principales

- Next.js 16
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons

## Estructura del proyecto

- `src/app` - rutas principales de la aplicación
- `src/components` - componentes reutilizables
- `src/data` - información personal, experiencia y proyectos
- `public/assets/perfil` - imagen de perfil y CV

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre la aplicación en:

```text
http://localhost:3000
```

## Compilar para producción

```bash
npm run build
```

## Funcionalidades

- Hero principal con presentación profesional
- Experiencia mostrada con timeline y resumen por empresas
- Sección de proyectos con cards visuales
- Bloque de contacto con cotización y redes sociales
- CV descargable
